## 🔧 Configuration

### Current Settings
```dart
// lib/main.dart
const bool kOfflineMode = true;  // ✅ Offline mode enabled
```

This means:
- ✅ No Firebase setup needed
- ✅ Works without internet
- ✅ All data stored locally
- ✅ Perfect for development

### To Enable Firebase (Optional)
1. Change `kOfflineMode = false` in `lib/main.dart`
2. Configure Firebase (see `FIREBASE_AUTH_SETUP.md`)
3. Enable Google Sign-In
